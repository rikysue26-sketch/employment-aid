# 高校毕业生就业精准帮扶 Agent 平台

面向高校招生就业处、二级学院和辅导员的B端产品。帮助高校汇总毕业生就业状态、识别需要重点帮扶的学生、进行人岗匹配、制定帮扶计划，并生成就业工作报告。

> ⚠️ 所有学生数据均为虚构模拟数据，不代表任何真实个人信息。

## 快速开始

### 环境要求

- Node.js 18+
- npm 10+

### 安装与启动

```bash
# 1. 安装依赖
npm install

# 2. 复制环境变量
cp .env.example .env

# 3. 初始化数据库
npx prisma db push

# 4. 生成模拟数据
npx tsx scripts/seed.ts

# 5. 启动开发服务器
npm run dev
```

浏览器打开 http://localhost:3000 即可使用。

### 一键重置演示数据

```bash
npm run db:reset
```

或通过系统内的「演示模式」入口重置。

## Mock Agent 与真实AI切换

系统默认使用 **Mock Agent 模式**（规则引擎），无需任何API密钥即可完整演示。

### 切换到真实AI

编辑 `.env` 文件：

```env
AI_MODE="real"
OPENAI_API_KEY="your-api-key"
OPENAI_BASE_URL="https://api.openai.com/v1"
OPENAI_MODEL="gpt-4o-mini"
```

重启服务即可。Mock Agent 使用透明规则引擎，真实AI模式调用 OpenAI 兼容接口。

## 已实现功能

### 核心页面

1. **角色切换页** — 管理员/辅导员/领导三个演示身份 + 演示模式入口
2. **就业驾驶舱** — 毕业生总数、落实率、重点帮扶人数、本周投递/面试/录用、学院进展、八周趋势、风险分布、求职障碍分布、Agent任务记录
3. **学生管理** — 搜索、多维度筛选（学院/专业/状态/风险/活跃度）、批量风险分析、分页
4. **学生详情** — 基本信息、求职意向、技能标签、简历、投递/面试/沟通记录、风险依据、推荐岗位、帮扶任务时间线；可操作：重新风险分析、匹配岗位、简历优化建议、沟通提纲、创建帮扶任务、更新就业状态、添加沟通记录
5. **重点帮扶中心** — Agent建议的帮扶学生列表、风险依据、推荐措施、辅导员确认/驳回、调整优先级、批量创建任务
6. **岗位管理** — 岗位列表、搜索、筛选、新增/编辑岗位
7. **人岗匹配** — 两层匹配（硬性条件+软性匹配）、满足/不满足条件展示、推荐原因、能力缺口、确认推荐/排除/加入待投递、生成推荐消息（需审批后发送）
8. **帮扶任务中心** — 看板和列表两种视图、任务创建/状态更新/跟进记录
9. **Agent工作台** — 任务拆解、逐步执行、数据读取记录、分析进度、发现的问题、待人工确认事项、结构化结论（区分事实/计算/推测/缺失/待确认）、操作日志
10. **报告中心** — 周报/领导摘要/帮扶进展/供需分析/任务完成情况，支持预览/复制/导出Markdown/打印PDF

### 风险分析规则引擎

透明可解释的规则系统，包含但不限于：

- 连续30/60天无投递 → 中/高风险
- 投递超过15次无面试 → 高风险
- 多次面试未获录用 → 中风险
- 学历不匹配投递 → 高风险
- 目标岗位与专业/技能不匹配 → 中风险
- 简历表达不足 → 中/低风险
- 临近毕业且活动不足 → 高风险
- 有录用但状态未更新 → 数据异常（高风险）
- 家庭经济困难 → 优先服务（不影响风险评价）

每个结论包含：触发规则、数据依据、建议行动、是否需人工审批。

### 人岗匹配引擎

- **第一层（硬性条件）**：学历、专业、截止日期、城市接受度、岗位状态
- **第二层（软性匹配）**：技能匹配、求职意向、行业偏好、薪资期望、简历相关度、可迁移能力

硬性条件不满足时明显提示，不会通过高软性分数掩盖。

### 演示案例

| 案例 | 场景 |
|------|------|
| A | 本科生投递要求硕士学历的算法岗位，20次无面试 |
| B | 技术能力好但简历描述极差 |
| C | 60天无投递，辅导员联系未回复 |
| D | 网络工程专业投产品经理，技能更适合网络安全/运维 |
| E | 多次面试均未通过 |
| F | 已获录用但状态仍显示未落实去向（数据异常检测） |

### 数据安全约束

- 禁止使用性别、民族、疾病等敏感信息判断就业风险
- 家庭经济情况仅用于服务优先级，不降低就业评价
- AI只提建议，重点帮扶名单和对外消息必须由辅导员确认
- 所有对外消息需经人工审批后方可发送
